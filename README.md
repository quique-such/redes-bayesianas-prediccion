# Predicción académica con redes bayesianas

Modelo probabilístico que predice la nota de un examen a partir de hábitos del estudiante (horas de estudio, sueño, asistencia). Compara estructuras expertas frente a estructuras aprendidas de los datos, con inferencia y análisis de sensibilidad.

**Tecnologías:** Python · pgmpy · Machine Learning
